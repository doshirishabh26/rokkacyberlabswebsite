5) Bulk Call Editor - Mass Schedule Updates

Company operators can bulk-edit call times, types, or import/export via spreadsheet for rapid schedule updates.

Bulk Editor Capabilities LIVE

  • Select multiple calls via checkboxes; apply call type / start time / end time to all at once.
  • Export call schedule to CSV with timezone and valid call types as headers.
  • Paste from spreadsheet: automatic format detection, timezone validation, overnight-boundary detection.
  • Live preview of changes before commit: shows per-call before/after side-by-side.
  • Validation warnings for skill/call-type mismatches (e.g., "Shop Call not allowed for Production Assistant").

Data Integrity & Safety LIVE

  • No changes applied until user confirms in preview modal.
  • Duration calculated correctly across date boundaries (e.g., 22:00 to 02:00 = next day, 4h).
  • All pasted/imported values validated against allowed call types per skill/position.
  • Timezone hint enforced: all times must be in job's configured timezone (e.g., America/Chicago).

6) Admin Skills Management - Taxonomy & Call Type Restrictions

Internal admin portal for managing the skill taxonomy, minimum hours, specialties, and allowed call types per discipline.

Skills Admin Features LIVE

  • Search skills across name, category, and aliases with 350ms debounce.
  • Add/edit skill: name, category, aliases, minimum hours (0-10, step 0.25), enabled toggle.
  • Assign allowed call types per skill (e.g., "Shop Call" restricted to certain disciplines).
  • Bulk delete selected skills with confirmation.
  • Real-time sync to DynamoDB; all changes live to crew/company job creation flows.

System Impact LIVE

  • Crew position creation: discipline picker populated from skills table (no hardcoded fallback).
  • Call type validation: bulk editor and manual entry prevent invalid skill/call-type combos.
  • AI schedule generation: uses live allowed call types to avoid generating invalid calls.
  • Job search filters: crew discipline selections match admin-defined skills exactly.
