3) Live Demo Script

15-minute walk-through. Three personas: Best company (W2-enabled), Rishabh Doshi (crew with home set in Elizabeth NJ), SCN admin.

Admin → set Cast & Crew customer ID + W2 fee defaults. Companies → Best company → Payroll Partner card → enter TEST-CC-001 (already seeded) and confirm 2.7% processor + $0 per-check are pre-filled.
Company → create W2 job (or open the seeded one). "W2 End-to-End Test — NYC Arena Show" at MSG. Walk through Job Type → Event Details (Google Places venue autocomplete) → Crew Positions (Payroll Classification picker shows W2).
Send Offer dialog. Pick a crew, send the offer. Note the "W2 Position" chip in the dialog title and the "Send W2 Offer" button.
Crew → My Jobs. Log in as Rishabh — offer tile shows the W2 chip with tooltip. Click into the offer.
Counter-offer. Open Messages → toggle "Counter rate" → bump to $85/hr → send. Switch to company → see the message + the application's proposedRate is now $85.
Cost Estimate. Back on the job detail, expand any W2 crew row in the breakdown: FICA (7.65%) + SUI (4.10%) + WC (per labor type) + Local / other employer tax (0.34% NYC MCTMT). Local withholding (crew) shows as employee-side info, not in company cost.
Generate W2 Payroll Batch. Click the button on the cost-estimate card → .xlsx downloads → open in Excel → walk through the 4 sheets. Highlight the Employer Taxes sheet (state-aware labels: "State Unemployment SUI (NY)", "Local Employer Tax (New York)") and the Employee Withholding sheet showing resident/non-resident class per crew.
Crew home location gate. As a crew member without a home city set, refresh — the non-dismissable "Add your home city" modal appears. Wording references payroll tax + travel.
Admin → Payroll Rules. Expand NY → see the city overrides table with split Resident and Non-Resident columns. Edit any row → see FICA & FUTA fields are read-only with "Federal — fixed" chips, WC is flagged "Fallback only".

4) Notes & Open Items

SCN does not touch W2 money. Cast & Crew is the Employer of Record — they invoice the company, run the paychecks, file 941s, and issue W2s at year-end. We hand off data via the Excel batch. This keeps us out of money-transmitter territory and aligns with the June 3 dev-meeting decision.
PayrollTaxAPI doesn't model resident local rates. Verified by direct API testing — residenceState=MI still returns Detroit at 1.2%, not the resident 2.4%. So we treat the cached value as the non-resident rate and admin enters resident rates via the manual-override "Resident" field. 26 cities seeded; 1-hour ops task to add more when needed.
Paused per June 3 meeting: Complex overtime rule logic (blended W2 rates, IATSE OT premiums, 7th-day premium edge cases) is on hold pending Cast & Crew clarification. The basic federal (40 hr/wk × 1.5) + CA daily (8 hr × 1.5, 12 hr × 2) + meal-penalty math works today and drives every estimate.
Open follow-ups (next sprint): admin UI for editing per-company W2 fees inline (handler already exists, just wire the form), prominent "Download Payroll Batch" entry in the Job actions menu, and credit-card gateway alternatives to Stripe (deferred from earlier meeting).
