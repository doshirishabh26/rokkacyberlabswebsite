3) Live Demo Script

12-minute walk-through. Three personas: Best company (PM), Jenny Rosen (crew with an active offer), SCN admin.

Company → send a W2 offer. Best company → open the seeded "Beachball Interview with Shane" job → applications tab → send offer to Jenny with hourly $75. Click the new single "Message" chip on the row — opens the offer chat with one welcome system bubble.
Crew → see the offer chat. Log in as Jenny → sidebar shows a badge on Offer Negotiations. Click in → the new /messages/offers list shows "Jenny Rosen · Beachball Interview with Shane · This is nice offer, I have got, let me test it". Open the row.
Crew → counter. Click the "Send counter" icon next to the composer → counter card opens with payroll type + amount (rate type locked to hourly). Bump to $85 → preview line at the bottom shows "Event total ≈ $4,250 (5 days × 10h × $85)". Send.
Company → respond. Switch to company → the row chip is now a primary Respond CTA. Open → the counter bubble has inline [Accept] [Counter] [Decline]. Click Accept — chat shows a decision pill, the row chip flips back to neutral "Message".
DM flow. From the company side, click Message on a different applicant who hasn't been hired → DM opens (no offer chat). Note the "via Best company" tag on the crew's side once they reply.
Reactions + attachments. In any thread, react with 👍 on a bubble, then click the paperclip → upload a PDF call sheet → see the inline preview + downloadable chip on the other side.
Admin → Federal Rules. SCN admin → Federal Rules sidebar entry → propose a new FICA rate → second admin approves → row goes from pending → live with the same UX state-rules already had.
Admin → City Tax Rates. Open the overhauled City Tax Rates page → use the new state filter → bulk-approve 3 pending Detroit rows → click the diff icon to confirm the old vs new resident / non-resident split → CSV export.
W2 invoice for a completed job. Open any job marked completed → cost-estimate card → "Download W2 Invoice" → walk through the 4-sheet xlsx.

4) Notes & design decisions worth calling out

Why DMs and Offer Negotiations are separate surfaces. Offer chats are bound to one application, drive application.status, archive on resolution, and carry the structured counter/decision bubbles. DMs are forever 1:1 and never archive. Mixing them would break the offer→job association and the Accept/Counter/Decline state machine.
URL fragment delimiter fix. The DM conversation id format dm#userA#userB uses #, which is the URL fragment marker. We had to encodeURIComponent at every interpolation site (9 RTK Query templates + 6 navigate calls) — otherwise routes truncated to /messages/dms/dm. AWS IVS also rejects # in tag values, so room tags get sanitized.
Federal sentinel pattern. Federal rules live in the same scn-state-rules DDB table with state = '__FEDERAL__'. This inherits the existing 4-eyes approval workflow with zero schema migration. listStateRules filters out the sentinel.
Still pending for next sprint. Cross-job persistent crew rosters (today every Call Group is scoped to a single job). Group DMs / threaded replies. Push notifications for mobile clients. Offer-chat search.
